Inventory Management System API

This is a backend API for an inventory management system built using Django REST Framework (DRF). It supports CRUD operations, JWT authentication, Redis caching, and logging.

🔗 Quick Links

  • Django Admin Panel

📌 API Endpoints

Authentication

  • POST /api/auth/register/ – Register user
  • POST /api/auth/login/ – Generate JWT
  • POST /api/auth/token/refresh/ – Refresh JWT

Items

  • GET /api/items/ – List all items
  • GET /items/<id>/ – Retrieve item by ID
  • POST /api/items/ – Create item
  • PUT /items/<id>/ – Update item
  • DELETE /items/<id>/ – Delete item

🧰 Tech Stack

  • Django & Django REST Framework
  • PostgreSQL or SQLite
  • Redis (Caching)
  • JWT Authentication
  • Docker (optional)

📦 Features

  • JWT-secured API
  • CRUD operations on inventory items
  • Redis-based caching
  • Error handling and logging
  • Unit test coverage
